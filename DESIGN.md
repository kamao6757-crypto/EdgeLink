# EdgeLink interface

The user's screenshot is the visual authority. Preserve the charcoal sidebar, saturated blue active item, white outline icons and the eight Chinese navigation labels. This pinned direction takes precedence over generated concepts.

Use a quiet desktop control interface: 212px sidebar, content up to 1100px, clear section headings, compact forms, real tables and purposeful status panels. Main background #181b23, sidebar #2d303c, surface #232732, blue #467edb, text #eef1f7, secondary #b5bed0. Use the native Windows Chinese UI face and tabular numerals for measured data.

Selected navigation, focus and operation status have separate meanings. Green denotes a measured healthy state; amber denotes an unmet setup step. Never invent connected state, geographic results, traffic or nodes. Empty states explain the next action. Icons are consistent authored outline SVG. The popup is a smaller control surface using the same palette.
